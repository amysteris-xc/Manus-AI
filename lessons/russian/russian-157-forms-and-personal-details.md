## Core pattern
The most common labels on simple forms use short nouns and set phrases. Learn the labels and exact, literal translations.

| Russian | Precise English translation |
|---|---|
| Фамилия | Surname (family name) |
| Имя | Given name (first name) |
| Отчество | Patronymic (middle name based on father's name) |
| Дата рождения | Date of birth |
| Адрес | Address |

## Concise explanation
Forms in Russian typically list short noun labels (Фамилия, Имя, Отчество) often without verbs; you supply the corresponding noun phrase. One common confusion: "Отчество" is a cultural element (a patronymic) that many foreigners do not have; on international forms it may be optional or left blank. Also, when filling online forms, count characters carefully: Cyrillic letters are multibyte in UTF-8, which can affect byte-limited fields (e.g., a 100-byte limit is not the same as 100 characters).

## Worked dialogue
А: Здравствуйте. Как ваши фамилия и имя?
*Hello. What are your surname and given name?*

Б: Фамилия — Иванов, имя — Сергей.
*Surname — Ivanov, given name — Sergey.*

А: А есть отчество?
*And is there a patronymic?*

Б: Нет, у меня нет отчества; я использую только имя и фамилию.
*No, I don't have a patronymic; I use only my given name and surname.*

А: Пожалуйста, укажите дату рождения в формате ДД.ММ.ГГГГ.
*Please provide the date of birth in the format DD.MM.YYYY.*

Б: 15.07.1990. Это вымышленная дата для примера.
*15.07.1990. This is a fictional date for the example.*

## Guided practice
1. Translate these labels into English: Фамилия, Имя, Отчество, Дата рождения, Адрес. (Do not provide real data.)
2. Write a fictional surname and given name in Cyrillic (two words), and provide an English transliteration next to each. Use clearly invented names.
3. Create a fictional address line in Cyrillic (one short sentence), then give a precise English translation. Ensure the address is fictional and non-specific.
4. Convert the fictional date "03.11.1985" into a Russian sentence: "Дата рождения: 03.11.1985." and translate it.
5. Practice a short form-filling sentence: write "Фамилия: ___; Имя: ___; Отчество: ___." Fill blanks with fictional entries and include English translations. Do not use any real personal data.

## Independent production exercise
Write 6–10 sentences in Russian (each with a precise English translation beneath) that simulate filling out a simple, fictional membership card. Include fields: Фамилия, Имя, Отчество (optional), Дата рождения, Адрес (fictional), and Контактный телефон (use a clearly fictional pattern like +7 900 000 00 00). Make sure every item is fictional and add one sentence reminding a reader not to share private data publicly.

Example structure requirement (yours should follow): one sentence per field plus one protective reminder sentence. Use Cyrillic for Russian sentences and provide precise English translations immediately under each.

## Spoiler: answers and model response
1. Model recall answers: "I am" — "Я (есть)" in simple contexts "Я есть" is uncommon; most often just "Я" + predicate. (Accept concise explanation.)
2. Nominative singular for "book": "книга".
3. Basic conversational "to have": use "у меня есть" (e.g., "У меня есть книга." = "I have a book.").
4. Byte-boundary validation: UTF-8 uses multiple bytes for Cyrillic characters, so a field limited to N bytes may hold fewer Cyrillic characters than N ASCII characters.
