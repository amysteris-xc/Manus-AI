## Core pattern
A concise teaching paragraph:
Use this simple sequence for a mini-paragraph: state your opinion with я думаю + clause, give a reason with потому что + clause, and add a limited illustrative example with например + short phrase. Keep the example explicitly illustrative, not a claim that proves everything.

| Russian | Precise English translation |
|---|---|
| Я думаю, что это хорошая идея, потому что это экономит время. | I think that this is a good idea because it saves time. |
| Я думаю, что фильм интересный, потому что сюжет неожиданный, например сцена в конце. | I think the movie is interesting because the plot is unexpected; for example, the scene at the end. |
| Я думаю, что кафе рядом удобно, потому что оно открыто до позднего вечера, например можно прийти после работы. | I think the nearby café is convenient because it is open late; for example, you can come after work. |

## Concise explanation
Form: Start with я думаю (I think) or simply Я считаю (I consider) + clause; add потому что (because) to give a reason; finish with например (for example) to give a specific, limited illustration. Meaning: this structure communicates an opinion, a supporting rationale, and one concrete instance that illustrates the rationale. Limitation/common confusion: an example introduced with например is an illustration, not proof of a universal claim — avoid saying например and then generalizing as if the example proves every case.

## Worked dialogue
А: Я думаю, что эта книжка полезная, потому что язык простой.
*I think that this book is useful because the language is simple.*

Б: Например, какие разделы кажутся простыми?
*For example, which sections seem simple?*

А: Например, упражнения в конце каждого урока и объяснения грамматики.
*For example, the exercises at the end of each lesson and the grammar explanations.*

Б: Я тоже так думаю, потому что упражнения короткие и понятные.
*I think so too because the exercises are short and clear.*

## Guided practice
1. Convert the English opinion "I think the pasta is tasty because it is fresh, for example the tomato sauce" into a single Russian sentence using я думаю, потому что, and например.
2. Write two short Russian sentences: first state "I think the park is quiet", then add a because clause with one reason.
3. Rewrite the sentence "I think the service is good" to add a limited example with например.
4. Combine the three elements into a 3–4 line mini-paragraph about a book or movie you know using the core pattern.
5. Mark the example in your paragraph explicitly as illustrative (use words like например or такой как) and add one brief sentence noting that the example is not proof of all cases (use простое указание that it is an illustration).

## Independent production exercise
Write a 6–10 sentence fictional mini-paragraph in Russian that follows this structure:
- Begin with a clear opinion using я думаю or Я считаю.
- Give at least one because clause using потому что that states a concrete reason.
- Include at least one sentence with например giving a limited illustration.
- Add one sentence that explicitly notes the example is only illustrative (e.g., Это только пример, not a proof).
Remember to keep vocabulary at a beginner-to-intermediate level and use correct grammar.
