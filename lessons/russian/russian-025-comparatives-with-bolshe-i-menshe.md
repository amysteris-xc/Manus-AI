# Russian 025 — Simple Comparisons with `больше` and `меньше`

**Estimated study time:** 25–35 minutes
**Prerequisites:** Russian 001–017 and the immediately preceding lessons
**Author:** Manus AI

## What you will be able to do

By the end of this lesson, you should be able to make controlled comparisons with **больше** “more/bigger” and **меньше** “less/smaller” using familiar objects and numbers.

## Retrieval practice

1. Translate **Я не учусь дома.**
2. Ask informally, “Are you at the library?”
3. Produce one short future sentence with **буду**.
4. From the previous C lesson, name one checked boundary that makes binary data processing safer.

## Core pattern

Use **больше** and **меньше** as comparison words in short, concrete sentences. This lesson compares fictional objects or quantities. It does not make claims about people, health, worth, or real possessions.

| Russian | Precise translation |
|---|---|
| больше | more; bigger |
| меньше | less; smaller |
| Парк больше. | The park is bigger. |
| Книг меньше. | There are fewer books. |

## Concise explanation

Start from the complete model phrase. Keep previously learned words in their established forms and change only the new element. This reduces errors and makes later review easier. Russian questions can keep statement word order; use a question mark and question intonation.

## Worked dialogue

> **А:** Парк больше?
> *Is the park bigger?*
>
> **Б:** Да, парк больше.
> *Yes, the park is bigger.*
>
> **А:** Книг больше?
> *Are there more books?*
>
> **Б:** Нет, книг меньше.
> *No, there are fewer books.*
