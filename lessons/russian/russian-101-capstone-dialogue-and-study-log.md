# Russian 101 — Capstone Dialogue and Study Log

**Estimated study time:** 25–35 minutes
**Prerequisites:** Russian 001–100
**Author:** Manus AI

## What you will be able to do

By the end of this lesson, you should be able to produce an extended fictional conversation and a concise study log that integrates the course’s main communication patterns.

## Retrieval practice

1. Say one full model sentence from Russian 057 without looking.
2. Recall the difference between a current journey and a habitual journey.
3. State why a C byte buffer needs an explicit `size_t` length.
4. Translate one earlier polite request into English.

## Core pattern

The capstone combines accurate short clauses rather than demanding advanced literary style. Include identity, a plan, a condition, an opinion, a polite request, and a reflection on progress.

| Russian | Precise English translation |
|---|---|
| Я уже могу читать короткие тексты. | I can already read short texts. |
| Если будет время, я продолжу практику. | If there is time, I will continue practice. |
| Мне хотелось бы говорить увереннее. | I would like to speak more confidently. |

## Concise explanation

Build each statement from a reliable chunk before adding detail. Preserve the case, verb form, or connector shown in the model rather than translating word-for-word from English. Russian word order is flexible, but this lesson uses a neutral order so that the grammar pattern remains visible.
