## Core pattern
We use the fixed phrase `друг друга` (literally "each other / one another") with verbs in normal conjugation. `Друг друга` always uses the accusative form of `друг` (it looks like the same words in many cases) and follows the verb or direct object position like an ordinary object.

| Russian | Precise English translation |
|---|---|
| Мы видим друг друга. | We see each other. |
| Они помогают друг другу. | They help one another. |
| Вы понимаете друг друга? | Do you (plural/formal) understand each other? |

## Concise explanation
Form: Use the familiar verb conjugated for the subject (я, ты, он/она, мы, вы, они). Add `друг друга` (or the plural variant `друг другу` when idiomatically preferred) as the object to mean "each other." Meaning: expresses reciprocal action — two or more participants perform the same action toward one another. Limitation / common confusion: do not try to decline `друг друга` into many new cases in beginner practice; start by using it as shown (accusative-like object). Also note: for verbs that require a different case (e.g., with prepositions or verbs that take dative), use the appropriate construction learned earlier rather than forcing `друг друга`.

## Worked dialogue
А: Мы встречаемся завтра в парке.
*We are meeting each other tomorrow in the park.*

Б: Хорошо — во сколько мы встречаемся?
*Okay — at what time are we meeting each other?*

А: В семь. Я позвоню тебе, если опоздаю.
*At seven. I will call you if I am late.*

Б: Отлично. Видим друг друга в семь.
*Great. We will see each other at seven.*

## Guided practice
1. Rewrite the sentence "Они понимают языки." to say "They understand each other." Use `друг друга`.
2. Translate into Russian: "We help each other with homework."
3. Make a yes/no question in Russian using `друг друга` and the verb "видеть" for вы (plural/formal).
4. Convert "Она зовёт брата." into a reciprocal action for two sisters calling each other.
5. Create a short three-word Russian sentence meaning "They call each other." Use a verb you already know.

## Independent production exercise
Write 6–10 Russian sentences (use Cyrillic) telling a very short fictional scene about two friends planning to cooperate. Include at least three different verbs from this lesson (e.g., встречаться, помогать, понимать, видеть, звонить) and use `друг друга` at least twice. After each Russian sentence, provide an exact English translation on the next line (italicized is fine). Keep sentences simple and concrete (people meet, help, or understand each other). Limit case complexity — use `друг друга` as the direct object pattern shown.
