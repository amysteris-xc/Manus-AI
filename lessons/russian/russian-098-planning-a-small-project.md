# Russian 098 — Planning a Small Project

**Estimated study time:** 25–35 minutes
**Prerequisites:** Russian 001–097
**Author:** Manus AI

## What you will be able to do

By the end of this lesson, you should be able to describe a fictional small project with goals, steps, and a deadline using known future and necessity forms.

## Retrieval practice

1. Say one full model sentence from Russian 057 without looking.
2. Recall the difference between a current journey and a habitual journey.
3. State why a C byte buffer needs an explicit `size_t` length.
4. Translate one earlier polite request into English.

## Core pattern

Combine **планирую**, **нужно**, **сначала**, and a time phrase. Keep the project harmless and educational, such as a reading plan or study notebook.

| Russian | Precise English translation |
|---|---|
| Я планирую маленький проект. | I am planning a small project. |
| Сначала нужно собрать материалы. | First it is necessary to collect materials. |
| Потом я напишу план. | Then I will write a plan. |

## Concise explanation

Build each statement from a reliable chunk before adding detail. Preserve the case, verb form, or connector shown in the model rather than translating word-for-word from English. Russian word order is flexible, but this lesson uses a neutral order so that the grammar pattern remains visible.

## Worked dialogue

> **А:** Я планирую маленький проект.
> *I am planning a small project.*
>
> **Б:** Сначала нужно собрать материалы.

> **А:** Хорошо, спасибо.
> *Good, thank you.*
>
> **Б:** Пожалуйста.
> *You are welcome.*
