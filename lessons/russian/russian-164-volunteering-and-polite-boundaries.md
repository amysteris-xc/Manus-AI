## Core pattern
Use concise, consent-aware offers: state what you can do, give limits, then propose an alternative if necessary.

| Russian | Precise English translation |
|---|---|
| Могу помочь с этим заданием, но только вечером после восьми. | I can help with this assignment, but only in the evening after eight. |
| Я могу это сделать, но у меня будет только час. | I can do that, but I will only have one hour. |
| К сожалению, я не эксперт в этой теме; могу порекомендовать коллеге. | Unfortunately, I'm not an expert on this topic; I can recommend a colleague. |

## Concise explanation
Form: The typical polite structure is [offer verb + scope], then [limit phrase], optionally followed by [alternative]. Offer verbs include "мочь/смочь" (can), "готов(а)" (ready/willing), and "хотел(а) бы" (would like to). Limits are expressed with time phrases (например, "только вечером"), quantity ("только час"), or expertise ("не эксперт"). One common confusion: "могу" vs "могу помочь" — "могу" alone may sound abrupt; add the object or context to be clear. Also, using "извините, но..." is polite, but avoid combining apologies with passive-aggressive language — state the reason concisely.

## Worked dialogue
А: Можешь помочь с презентацией в пятницу?
*Can you help with the presentation on Friday?*

Б: Могу, но только утром до двенадцати.
*I can, but only in the morning before twelve.*

А: Если утром неудобно, можно в субботу?
*If morning is inconvenient, is Saturday possible?*

Б: В субботу у меня встреча; могу посмотреть слайды в воскресенье вечером.
*On Saturday I have a meeting; I can review the slides on Sunday evening.*

А: Понял(а), спасибо. А если нужно больше изменений, ты сможешь помочь?
*Got it, thanks. And if more changes are needed, will you be able to help?*

Б: К сожалению, не смогу взять много правок, но могу порекомендовать ещё одного человека.
*Unfortunately, I can't take many edits, but I can recommend another person.*

## Guided practice
1. Translate into Russian: "I can review your report, but I have only thirty minutes."
2. Write a short Russian sentence refusing a request because of lack of expertise, and offering an alternative.
3. Convert this offer into a softer form: "I will help" → make it consent-aware with a limit.
4. Role-play: write a two-line Russian exchange where you politely decline because of time, then suggest a later time.
5. Rewrite the sentence "Я помогу" to sound less forceful and more conditional/polite.

## Independent production exercise
Write a short fictional message (6–10 sentences) in Russian where you:
- Offer to help a neighbor with two concrete things (e.g., shopping, moving boxes).
- State a clear limit on time or quantity.
- If you cannot fully help, suggest an alternative person, time, or resource.
- Use at least one phrase from the Core pattern table.
Each Russian sentence must be accompanied by its English translation.
