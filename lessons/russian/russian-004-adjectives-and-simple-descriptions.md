## 1. Adjectives must agree with the noun

An **adjective** describes a noun. In Russian, a full adjective agrees with the noun it describes in gender, number, and case.[1] This lesson works only with **singular nominative** phrases, the form used for basic dictionary-style descriptions. Do not generalize these endings to every later sentence yet.

The adjective usually appears before the noun:

```text
новый стол
new table
```

The noun **стол** is masculine, so the adjective takes a masculine form: **новый**. Change the noun’s gender, and the adjective changes too.

```text
новая книга
new book

новое окно
new window
```

> **Agreement rule for today:** First identify the noun’s gender. Then choose the adjective form that belongs with that gender. Learn the phrase as one unit.

## 2. The first pattern: новый — new

The dictionary form of many adjectives is the masculine nominative singular form.[1] For the adjective **новый** “new,” use the following set.

| Noun gender | Adjective form | Example phrase | Translation |
|---|---|---|---|
| Masculine | но́вый | но́вый стол | new table |
| Feminine | но́вая | но́вая кни́га | new book |
| Neuter | но́вое | но́вое окно́ | new window |

Say the three forms as a rhythm:

```text
но́вый — но́вая — но́вое
```

The exact spelling change is visible at the end of the adjective. The noun’s ending remains a useful clue: **стол** ends in a consonant and is masculine; **книга** ends in **а** and is feminine; **окно** ends in **о** and is neuter.

## 3. A second pattern: маленький — small

Use a second adjective to make the agreement pattern more flexible. **Ма́ленький** means “small.” Its singular forms are:

| Noun gender | Adjective form | Example phrase | Translation |
|---|---|---|---|
| Masculine | ма́ленький | ма́ленький стол | small table |
| Feminine | ма́ленькая | ма́ленькая кни́га | small book |
| Neuter | ма́ленькое | ма́ленькое окно́ | small window |

Do not try to strip letters from every adjective and rebuild it mechanically. Russian has spelling patterns and exceptions. At this stage, memorize a few complete form sets and attach each form to a known gender.

## 4. Build descriptions from a gender package

Russian 003 taught each noun as a gender package:

```text
стол — masculine — он
книга — feminine — она
окно — neuter — оно
```

Now extend each package with an adjective:

| Noun package | New description package |
|---|---|
| стол — masculine — он | новый стол; маленький стол |
| книга — feminine — она | новая книга; маленькая книга |
| окно — neuter — оно | новое окно; маленькое окно |

When describing objects, **он**, **она**, and **оно** are normally translated as “it.” They match grammatical gender, not a physical property of the object.

| Russian | Precise translation |
|---|---|
| Это но́вый стол. Он но́вый. | This is a new table. It is new. |
| Это но́вая кни́га. Она́ но́вая. | This is a new book. It is new. |
| Это но́вое окно́. Оно́ но́вое. | This is a new window. It is new. |

In present-tense Russian descriptions, a word matching English “is” is often absent. For today, learn the complete short patterns rather than adding a separate word for “is.”

## 5. Ask “what kind?”

To ask for a simple description, Russian changes the question word to agree with the noun’s gender.

| Noun gender | Question | Example answer |
|---|---|---|
| Masculine | Како́й э́то стол? | Э́то но́вый стол. |
| Feminine | Какая́ э́то кни́га? | Э́то ма́ленькая кни́га. |
| Neuter | Како́е э́то окно́? | Э́то но́вое окно́. |

These questions mean approximately “What kind of table/book/window is this?” The word order is not the main lesson; use each line as a memorized model.

> **Pronunciation note:** In **какая́**, the final **я** carries the stress. Marked stress supports accurate practice now; ordinary Russian writing usually omits the accent mark.

## 6. Worked dialogue: describe three objects

Read the dialogue slowly once with the study stress marks. Then cover the English and say both roles aloud.

> **А:** Что э́то?
> *What is this?*
>
> **Б:** Э́то но́вый стол.
> *This is a new table.*
>
> **А:** Како́й э́то стол?
> *What kind of table is this?*
>
> **Б:** Он но́вый.
> *It is new.*
>
> **А:** А э́то?
> *And this?*
>
> **Б:** Э́то ма́ленькая кни́га. Она́ ма́ленькая.
> *This is a small book. It is small.*
>
> **А:** А окно́?
> *And the window?*
>
> **Б:** Э́то но́вое окно́. Оно́ но́вое.
> *This is a new window. It is new.*

Read the same Russian without study accents:

```text
Что это?
Это новый стол.
Какой это стол?
Он новый.
А это?
Это маленькая книга. Она маленькая.
А окно?
Это новое окно. Оно новое.
```

Notice the matching pairs: **новый / он**, **маленькая / она**, and **новое / оно**.

## 8. Independent production exercise

Use safe, ordinary objects from an actual or imagined room. Do not include names, addresses, or personal records. Select one masculine, one feminine, and one neuter noun from Russian 003 or from a reliable reference.

For each noun, write one question and one answer. Keep the adjective and noun in the same gender.

```text
Какой это [masculine noun]?
Это новый [masculine noun]. Он новый.

Какая это [feminine noun]?
Это маленькая [feminine noun]. Она маленькая.

Какое это [neuter noun]?
Это новое [neuter noun]. Оно новое.
```

Read the six lines aloud twice. On the second pass, cover the English and the gender labels. If an ending feels uncertain, return to the noun package first, then select the adjective form.
