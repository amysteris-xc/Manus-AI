## Core pattern

Ordinal numbers answer “which one?”: **первый**, **второй**, **третий**. Dates use an ordinal form, but this lesson keeps the pattern to familiar calendar notices.

| Russian | Precise English translation |
|---|---|
| первый урок | the first lesson |
| второй день | the second day |
| Сегодня третье мая. | Today is the third of May. |

## Concise explanation

Build each statement from a reliable chunk before adding detail. Preserve the case, verb form, or connector shown in the model rather than translating word-for-word from English. Russian word order is flexible, but this lesson uses a neutral order so that the grammar pattern remains visible.
