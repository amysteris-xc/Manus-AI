Learning objective: write a concise fictional meeting follow-up that records decisions and open questions.

## What you will be able to do
Write a short meeting follow-up in Russian that clearly lists confirmed decisions (решения) and outstanding questions (вопросы), using concise, neutral phrasing and avoiding language that implies binding legal or financial commitments.

## Retrieval practice
1. Recall the Russian past-tense formation for perfective verbs from Russian 096–099. Write one example sentence describing a completed action in a meeting.
2. Recall the instrumental case usage from Russian 100. Describe in one sentence who led the meeting using the instrumental.
3. Recall the use of conjunctionы and particles from Russian 101. Combine two short clauses with a conjunction to state a decision and a next step.
4. Recall a C concept about byte boundaries or validation: explain in one sentence why clearly separating confirmed decisions from open questions is like validating tagged unions (ensures each variant is handled).

## Core pattern
Concise teaching: Use short, declarative sentences. Start with a one-line header "Решения" for confirmed items and "Вопросы" for open items. Use verbs in past tense for decisions already made and present/future for actions to be taken. Keep each list item to one sentence.

| Russian | Precise English translation |
| --- | --- |
| Решения: проект запущен с согласованным графиком. | Decisions: The project is launched with an agreed timeline. |
| Решения: встреча по продукту будет проходить еженедельно по средам. | Decisions: The product meeting will occur weekly on Wednesdays. |
| Вопросы: требуется уточнить бюджет и сроки у финансового отдела. | Questions: It is necessary to clarify the budget and deadlines with the finance department. |
| Вопросы: кто отвечает за документирование — Маша или Сергей? | Questions: Who is responsible for documentation — Masha or Sergey? |

## Concise explanation
Form: Start with headers Решения and Вопросы, then list short sentences. Use past tense (perfective or past imperfective depending on aspect) for confirmed decisions and infinitive or future/present constructions for tasks or open questions. Meaning: This format separates what is settled from what still needs resolution. Limitation/common confusion: Russian aspect (perfective vs. imperfective) affects nuance; using imperfective past can imply ongoing or habitual action rather than a single confirmed decision — prefer perfective past for clear, one-time decisions when available.

## Worked dialogue
А: Мы приняли решение по срокам проекта.
*We made a decision about the project deadlines.*

Б: Какие именно сроки утвердили?
*Which exact deadlines did we approve?*

А: Дедлайн первого этапа — 15 октября; ответственный — команда разработки.
*The deadline for the first stage is October 15; the responsible party is the development team.*

Б: Хорошо. Вопрос по бюджету остаётся открытым.
*Good. The question about the budget remains open.*

## Guided practice
1. Write a one-line header "Решения" and list two fictional decisions in Russian, each one short sentence.
2. Write a one-line header "Вопросы" and list two open questions, each ending with a question mark.
3. Rewrite one decision using perfective past to emphasize it is finalized.
4. Convert an open question into a task with an assigned responsible person in one sentence.
5. Edit your follow-up to remove any wording that could be interpreted as a legal or financial commitment (avoid слова like "обязаны" without clarification).

## Independent production exercise
Write a 6–10 sentence fictional meeting follow-up in Russian. Begin with a short one-line subject (e.g., "Тема: Обновление по проекту"), then include a "Решения" section with 2–3 confirmed items in past tense and a "Вопросы" section with 2–3 open questions. Keep language neutral and precise; do not promise payments, legal obligations, or personal data sharing. Use Cyrillic and be concise.

## Spoiler: answers and model response
1. Example "Решения" items: "Решения: план работ утверждён." and "Решения: встреча будет каждую среду." — both are concise and use past/present as appropriate.
2. Example "Вопросы" items: "Вопросы: кто согласует бюджет?" and "Вопросы: нужны ли дополнительные ресурсы?" — both are questions ending with a question mark.
3. Model edited task conversion: "Назначено: согласовать бюджет — Иван до 30 сентября." — shows conversion of a question into an assigned task.
4. Example full model follow-up (6 sentences):
Тема: Обновление по проекту.
Решения: план работ утверждён.
Решения: первый релиз запланирован на 15 октября.
Решения: встречи по прогрессу будут по средам.
Вопросы: кто согласует бюджет?
Вопросы: нужен ли дополнительный ресурс по тестированию?
