# Russian 020 — Numbers One to Ten and Noun Awareness

**Estimated study time:** 25–35 minutes
**Prerequisites:** Russian 001–017 and the immediately preceding lessons
**Author:** Manus AI

## What you will be able to do

By the end of this lesson, you should be able to recognize and say the numbers one through ten, and use them for controlled counting practice without attempting the full Russian number-and-noun system.

## Retrieval practice

1. Translate **Я не учусь дома.**
2. Ask informally, “Are you at the library?”
3. Produce one short future sentence with **буду**.
4. From the previous C lesson, name one checked boundary that makes binary data processing safer.

## Core pattern

Numbers are useful vocabulary, but Russian number agreement has patterns that grow more complex after the smallest examples. Today, first learn the sequence and use it for counting objects in isolation. When you pair a number with a noun, treat the full phrase as a memorized chunk.

| Number | Russian |
|---|---|
| 1 | один |
| 2 | два |
| 3 | три |
| 4 | четыре |
| 5 | пять |
| 6 | шесть |
| 7 | семь |
| 8 | восемь |
| 9 | девять |
| 10 | десять |

## Concise explanation

Start from the complete model phrase. Keep previously learned words in their established forms and change only the new element. This reduces errors and makes later review easier. Russian questions can keep statement word order; use a question mark and question intonation.

## Worked dialogue

> **А:** Сколько книг?
> *How many books?*
>
> **Б:** Три книги.
> *Three books.*
>
> **А:** Сколько окон?
> *How many windows?*
>
> **Б:** Два окна.
> *Two windows.*

## Guided practice

1. Say the three new core words or phrases without looking.
2. Turn one model statement into a yes/no question.
3. Make one suitable statement negative with **не**.

## Independent production exercise

Count ten neutral objects aloud from one to ten. Then write two memorized chunks: **три книги** and **два окна**. Do not generalize these examples into a rule for every number yet.

## Spoiler: answers and model response

1. **Я не учусь дома.** means “I do not study at home.”
2. **Ты в библиотеке?**
3. A valid model is **Завтра я буду читать.**
4. A valid answer names an explicit count, a non-null pointer check, a file-result check, a bounds check, or an overflow check.
5. A model response uses the exact table and dialogue forms in this lesson.
