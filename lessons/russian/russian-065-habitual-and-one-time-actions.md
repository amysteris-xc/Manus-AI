# Russian 065 — Habitual and One-Time Actions

**Estimated study time:** 25–35 minutes
**Prerequisites:** Russian 001–064
**Author:** Manus AI

## What you will be able to do

By the end of this lesson, you should be able to separate habitual actions from a single completed event in short narratives.

4. Translate one earlier polite request into English.

## Core pattern

Use imperfective forms for regular routines and process. Use a perfective past form for a bounded completed event. Time words such as **обычно**, **вчера**, and **уже** help signal the distinction.

| Russian | Precise English translation |
|---|---|
| Обычно я читаю вечером. | I usually read in the evening. |
| Вчера я прочитал статью. | Yesterday I read an article to completion. |
| Она часто пишет сообщения. | She often writes messages. |

## Concise explanation

Build each statement from a reliable chunk before adding detail. Preserve the case, verb form, or connector shown in the model rather than translating word-for-word from English. Russian word order is flexible, but this lesson uses a neutral order so that the grammar pattern remains visible.
